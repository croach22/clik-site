Here's a podcast episode.

PLAN FIRST
List the top 10 clip segments, up to 90 seconds each. For each one:
- the concept in a sentence
- the title card text you would put on it
- roughly how long it runs
- 3 hook quotes from the body that I can pull to the front. These should be 5-10s quotes from the body that spark curiosity.

When you provide the concepts - ask me if I want to create clips with the hook lifted to the beginning, or I want to create continuous clips that follow the linear storyline or discussion.

Also ask me how tight I want the pacing. Tell me that by default you'll cut pauses over 1 second, and ask if that sounds right or if I want it tighter.

Don't build anything until I've picked from the list.

THEN BUILD
Ask me to confirm which concepts and hook pairings to build, then build for each:

Vertical clips with my default caption style. No B-roll. For the title card - use the basic title card with white background. The duration of this title card should match the hook lift duration OR be 6s if it's not a hook lift mode.

If I don't have a default caption style, tell me to go to the brand guide from the home screen and save a default caption style, then come back here to add it to the plan.
